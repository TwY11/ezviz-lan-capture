# v3.0 · 萤石局域网采集

首个公开版本。Android 7.0及以上，arm64设备。

## 功能

- 默认8帧/秒、32kHz、2秒采集，普通模式只保留JPG与重采样后的WAV。
- 帧率、时长、输出采样率可配置；保留独立10秒音画对照与声谱图、浏览器查看页面。
- 局域网设备登录与播放，无AccessToken设置，不申请手机摄像头/麦克风权限。
- 只导出本次登录；下一次登录成功会删除应用内旧会话，请及时导出。

## 检查

24项单元测试通过，Lint无错误；7种PCM输出采样率已通过手机端测试。真实摄像头默认采集验证为16张有效图片及一个32kHz单声道PCM16 WAV。该次音频2.048秒，保留完整AAC帧，无补静音。
